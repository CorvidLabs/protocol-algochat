# Documentation scope

`docs/proposals/pq-audit-spike.md` records parameter sizes, framing budgets,
the offline harness command and the proposed independent-review surfaces.
`docs/proposals/post-quantum-pair-secret.md` remains shelved/unshipped and
qualifies its two-note estimate by the complete framing and sender-wrap budget.
This packet preserves both files; it does not adopt their proposed construction.

Preserve the distinction between primitive probe and application audit. Node
native and Web Crypto share OpenSSL and are not cross-implementation proof.
Random round trips/negative cases are not NIST known-answer testing, FIPS
validation, timing review, a quantum attack or evidence of quantum resistance.
Transport/authentication/hybrid-combiner/recovery integration is absent. Phrase
restoration continues to exclude forward secrecy for restorable history.

No spec text changes or materialization deltas belong to this no-spec-change
draft. Canonical obligations and permanent IDs remain untouched. Human
approval, implementation acceptance and lifecycle closure remain pending.
